API de reconocimiento facial

Identifica personas con una llamada.

FaceCore registra varias muestras del rostro en embeddings de 128 dimensiones y devuelve una decisión de identidad para verificar asistencia.

Una integración sencilla

Del rostro a la respuesta.

El cliente envía embeddings, PHP protege la sesión y Node.js consulta PostgreSQL con pgvector.

01 / REGISTRO

Guarda varias muestras

Envía de 1 a 10 embeddings de 128 valores para representar distintas poses del mismo usuario.

02 / AUTENTICACIÓN

Protege la petición

Usa Authorization: ApiKey <tu_api_key> o el header X-API-Key.

03 / DECISIÓN

Obtén una respuesta

La API compara con distancia euclidiana, aplica el umbral 0.60 y rechaza coincidencias ambiguas.

Referencia rápida

Dos endpoints, un flujo.

Ambos requieren API key. Cada vector facial debe contener exactamente 128 valores numéricos.

POST

Registrar rostro

Asocia entre 1 y 10 muestras a un usuario. También acepta el campo antiguo embedding para una sola muestra.

POST /api/rostros/registrar
    Authorization: ApiKey <tu_api_key>

{
  "usuario_id": 42,
  "embeddings": [
    [0.12, -0.08, ... 125 valores más ...],
    [0.10, -0.06, ... 125 valores más ...]
  ]
}

Respuesta: { "ok": true, "muestras": [...] }
POST

Identificar rostro

Busca la muestra más cercana. Acepta si la distancia euclidiana es menor que 0.60 y no hay ambigüedad.

POST /api/rostros/identificar
Authorization: ApiKey <tu_api_key>

{
  "embedding": [0.12, -0.08, ... 125 valores más ...]
}

Respuesta: {
  "encontrado": true,
  "usuario_id": 42,
  "distancia_euclidiana": 0.42,
  "ambigua": false
}
